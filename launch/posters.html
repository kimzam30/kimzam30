Nhako Beam
Alpha 0.1.0

Send anything.
Straight to them.

Open source file transfer that goes from one of your devices to another. Nothing is uploaded or kept in between.

No cloudDevice to device, encrypted end to end. On the same Wi‑Fi they find each other.
No size limitOnly your disk decides. A dropped link resumes from the last confirmed byte.
No accountPair once with a four‑word code or a QR code. Run your own relay in Docker if you like.
